# Motion Academy, Siddipet  Coaching Website

A responsive, single-page marketing site for an intermediate college with IIT-JEE/NEET coaching. 

## Tech Stack
- Next.js (App Router)
- Tailwind CSS
- lucide-react (Icons)

## Features
- Mobile-first responsive design
- Clean, trustworthy aesthetic with deep blue & orange accents
- All static data localized in `src/data/content.ts`
- Forms log directly to console (no backend)

## How to run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
